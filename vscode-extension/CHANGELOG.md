# Change Log

All notable changes to the "AquaDrop — Hydration Reminder" extension will be documented in this file.

## [0.1.1] - 2026-10-26

### Added
- **Realistic Water Drinking Sound**: Multi-stage synthesized drinking audio with realistic throat swallow resonance, rhythmic liquid gulps, and refreshing water droplet splash.
- **Spoken Voice Reminders**: Choose between **👧 Girl Voice** (warm, friendly alert), **👦 Boy Voice** (encouraging, confident alert), or **🔔 Water Chime Only**.
- **Interactive Voice Cards & Live Preview**: Added 3-card voice persona selector and one-click "Play Sound" live audio audition in both Sidebar and Dashboard.
- **Hydration Sound on Drink Water**: Taking a water break now immediately plays the authentic water drinking sound.

## [0.1.0] - 2026-10-24

### Initial Release
- **Activity Bar & Sidebar**: Live status countdown, today's break count, daily goal progress bar, and quick actions.
- **Interactive Dashboard**: Full editor dashboard with hydration metrics, preset snoozes, reminder interval controls, and 7-day break history.
- **Reliable Scheduler**: Configurable intervals (15m, 30m, 45m, 60m, 90m or custom), default 5-minute snooze, and overdue reminder prevention.
- **Desktop Notifications**: Native VS Code alerts with quick "Drink Water" and "Snooze" action buttons.
- **Theming & Appearance**: Full support for System (VS Code theme match), Light, and Dark themes.
- **Persistent State**: Progress and schedule persist across VS Code restarts.
- **Status Bar Integration**: Live ticking countdown and click-to-dashboard shortcut in the status bar.
- **Security & Privacy**: Strict Content Security Policy (CSP), local-only storage, zero telemetry, and zero third-party dependencies at runtime.
